# HIC-Website
*Need to have flask installed*
*Need to create a virtual enviroment*

To create and connect to the database
- in bash terminal type: mysql
- to create database type: create database bs_cafe
- to open the database: use bs_cafe
- to populate the database copy bs_cafe.sql into the terminal
after placing an order you can open the orders, orderitems, and payment_info tables to see the information about the order you just placed
*promotions, carts, and cartitems are not used*

To start the website either:
- open the app.py file in vscode and click run
- in a python terminal type: python app.py
you will be given a link like this: http://127.0.0.1:5000, enter this link into a browser to go to the site
